How it's made

No cameras. No stock footage. Just code and care.

  1. Drawn in code

    Every frame is drawn by a program: dots, light and a little physics. No stock clips, no AI-generated pictures. If something moves, someone wrote the rule that moves it.

  2. Music composed in code

    The music is written by code too, note by note, and timed so the strings arrive right when the story turns.

  3. Every fact sourced

    Numbers are checked against the papers and records they come from, and the sources are listed under every video.

  4. Every quote verified

    Famous names attract fake quotes. Each quote we use is traced back to where it was first printed. If it can't be traced, it doesn't go in.
